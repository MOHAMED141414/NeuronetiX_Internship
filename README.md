## 📁 Projects

### 🏨 Hotel Reservation System
A complete hotel management system with room booking, customer management, and availability tracking.

**Features:**
- Room reservation and cancellation
- Customer check-in / check-out logic
- Room availability status tracking
- Admin panel for management

**Tech:** `C++` `OOP` `File Handling`

---

### 📚 Library Management System
A library management system for book inventory, member management, and borrowing records.

**Features:**
- Add/remove/search books
- Member registration and management
- Borrow and return tracking with due dates
- Overdue detection

**Tech:** `C++` `OOP` `Linked Lists` / `Vectors`

---

### ✖️ Multiplication Learning Game
An interactive educational game to help users practice multiplication tables with score tracking.

**Features:**
- Randomized multiplication challenges
- Score and progress tracking
- Multiple difficulty levels

**Tech:** `C++`

---

### 🛒 Online Shopping Cart System
A simulated e-commerce shopping cart with product management and order processing.

**Features:**
- Add/remove items to cart
- Product catalog with prices
- Order total calculation with discounts
- Simple checkout flow

**Tech:** `C++` `OOP`

### 💰 Personal Finance Tracker
An application to track income, expenses, and generate financial summaries.

**Features:**

- Category-based tracking

### 🐾 Pet Adoption Game
A fun console-based game where users adopt and care for virtual pets.
